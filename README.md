# hlauncher

Android home launcher — web-based, AI auto-categorizes apps.

## Features
- AI auto-categorization (Claude API)
- 10 categories: Social, Games, Media, Tools, Finance, Health, Education, Travel, Shopping, Other
- App drawer with search
- Persistent storage (localStorage)
- PWA-ready + APK via GitHub Actions

## Build APK
Push to main branch → GitHub Actions auto-builds the APK → download from Actions tab.
